# Sistema de Gestión de Inventario

**Trabajo Práctico Integrador — Programación I**

**Carrera:** Tecnicatura Universitaria en Programación  
**Universidad:** Universidad Tecnológica Nacional (UTN)

## Descripción

Sistema de inventario desarrollado en Python para administrar las herramientas de una ferretería mediante un menú interactivo de consola.

## Funcionalidades

1. Cargar herramientas.
2. Mostrar inventario.
3. Consultar stock.
4. Generar un reporte de herramientas agotadas.
5. Dar de alta nuevos productos.
6. Actualizar el stock mediante ventas e ingresos de mercadería.
7. Salir del programa.

## Tecnologías utilizadas

- Python
- Visual Studio Code
- Git y GitHub

## Ejecución

Para ejecutar el programa, utilizar el siguiente comando:

`python inventario.py`
